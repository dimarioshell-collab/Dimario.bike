========================================
  СПОВІЩЕННЯ ПРО ЗАЯВКИ В TELEGRAM
========================================

Налаштовується ОДИН файл: tg-config.js

КРОК 1. Створіть бота
  • Telegram → @BotFather → /newbot
  • Ім'я: наприклад "Dimario Leads"
  • Username: наприклад dimario_leads_bot
  • Скопіюйте TOKEN

КРОК 2. Активуйте бота
  • Відкрийте свого бота в Telegram
  • Натисніть Start (/start)

КРОК 3. Дізнайтесь chatId
  • У браузері відкрийте:
    https://api.telegram.org/botВАШ_TOKEN/getUpdates
  • Знайдіть рядок:  "chat":{"id": 123456789
  • Це ваш chatId (число)

  Якщо порожньо {} — ще раз натисніть /start у бота
  і оновіть сторінку getUpdates.

КРОК 4. Відкрийте файл tg-config.js і вставте:

  botToken: '7123456789:AAH....',
  chatId:   '123456789',

КРОК 5. Перевірка
  1. Запустіть сайт (http://127.0.0.1:8080)
  2. F12 → Console
  3. Введіть:  dimarioTestTelegram()
  4. У Telegram має прийти повідомлення «Тест Dimario»

КРОК 6. Реальна заявка
  • Головна → «Залишити заявку» у підвалі
  • Або constructor.html → «Надіслати заявку»

Після цього кожна нова заявка приходитиме вам у Telegram:
  • ім'я клієнта
  • телефон / @нік
  • тип робіт / комплектація
  • опис і час

----------------------------------------
Група замість особистих повідомлень
  1. Створіть групу, додайте бота
  2. Дайте боту право писати
  3. chatId буде від'ємним, напр. -1001234567890
  4. Той самий getUpdates покаже id після повідомлення в групі
